# Improving Deep Neural Networks: Hyperparameter Tuning, Regularization and Optimization

**Course 2 of the [Deep Learning Specialization](https://www.coursera.org/specializations/deep-learning) by DeepLearning.AI**

This intermediate-level course focuses on the practical techniques used to train deep neural networks effectively and systematically. It covers how to diagnose model performance, reduce overfitting, improve optimization, tune hyperparameters, and build neural networks with TensorFlow.

## Course Overview

The course is organized into three main modules:

### 1. Practical Aspects of Deep Learning
- Train, development, and test sets
- Bias and variance analysis
- Weight initialization
- L2 regularization and dropout
- Input normalization
- Vanishing and exploding gradients
- Gradient checking

### 2. Optimization Algorithms
- Mini-batch gradient descent
- Exponentially weighted averages
- Momentum
- RMSprop
- Adam optimization
- Learning-rate decay

### 3. Hyperparameter Tuning, Batch Normalization and Programming Frameworks
- Hyperparameter tuning strategies
- Batch normalization
- Softmax regression
- Deep learning frameworks
- TensorFlow
